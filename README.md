## 特色功能
1. **3D 擬真雙頁翻頁**：立體紙張弧度、精裝單面封面。
2. **單頁超高清大圖**：300 DPI 印刷級高解析度、滑鼠滾輪支援最高 5x (500%) 巨幅顯微放大。
3. **網址帶頁碼直連 (URL Deep Linking)**：網址自動同步頁碼與模式（如 #page=12&mode=single），並支援一鍵複製分享。
4. **行動裝置與平板適配**：手機自動切換單頁大圖、支援原生左右滑動翻頁 (Swipe)、手機專屬自適應雙層底欄。
5. **快速檢索與跳章節**：頂部搜尋型號/案號即時過濾、左側目錄抽屜快速索引、底部固定「上一類別 / 下一類別」切換鍵。
